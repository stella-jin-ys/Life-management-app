# Life Management

A responsive wellbeing dashboard for noticing small wins, naming difficult feelings, checking physical health habits, and keeping one gentle next step visible.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Verify

```bash
npm test -- --run
npm run build
```

## Prototype data

This version stores interaction state only in the browser session. Community percentages and compliment responses are authored demo content; they are not live population research or responses from a connected AI service.
